# 🎯 Smart Résumé Screener

> **100% Local, zero-cost AI-powered résumé ranking with Ollama (`nomic-embed-text` & `llama3.2:1b`) and a hybrid multi-signal scoring engine. Portfolio-grade & Privacy-first.**

---

## 🔥 Project Overview

Smart Résumé Screener is a **portfolio-grade Applicant Tracking System (ATS)** that operates entirely offline. It uses local Ollama models (`nomic-embed-text` for embeddings and `llama3.2:1b` for chat reasoning) to intelligently rank candidates against a job description with transparent, explainable scoring. Because everything runs locally, **candidate data never leaves your machine**, ensuring 100% data privacy and zero API costs.

### Why this project stands out

| Feature | What makes it special |
| --- | --- |
| 🔒 **Privacy-First & Zero Cost** | 100% offline inference using local Ollama models. No API keys, no subscriptions, no data leaks. |
| 🔗 **Semantic Matching** | `nomic-embed-text` vectors + cosine similarity — goes beyond simple keyword matching. |
| 🧠 **Hybrid Scoring** | 5 weighted signals: embedding, keyword, experience, education, bonus skills. |
| 🤖 **Llama 3.2 Reasoning** | Human-like explanations: strengths, weaknesses, and hiring recommendations generated by the lightning-fast 1B parameter model. |
| 📚 **Skill Ontology** | ~190 alias mappings across 59 skills (`"ML"` → `"Machine Learning"`, `"k8s"` → `"Kubernetes"`). |
| 💾 **Embedding Cache** | SHA-256 keyed disk cache eliminates redundant embedding generation. |
| 📦 **Batch Processing** | Upload up to `MAX_RESUMES_PER_BATCH` (default 20) résumés per request. |
| 🐳 **Docker Ready** | One-command deployment with `docker compose up` (configured for host-to-container networking). |

### Scoring Formula

```
Final Score = (Embedding × 0.50)
            + (Keyword Match × 0.20)
            + (Experience Alignment × 0.15)
            + (Education Match × 0.10)
            + (Bonus Skills × 0.05)

```

| Signal | Weight | Method |
| --- | --- | --- |
| **Embedding Similarity** | 50% | Cosine similarity between JD and résumé `nomic-embed-text` embeddings |
| **Keyword Match** | 20% | % of JD skills found in résumé via 59-skill ontology |
| **Experience Alignment** | 15% | Candidate years vs. JD required seniority level |
| **Education Match** | 10% | Candidate degree vs. JD minimum education requirement |
| **Bonus Skills** | 5% | Premium in-demand skills (Docker, Kubernetes, LLMs, etc.) |

## ⚙️ Setup Instructions

### Prerequisites

* Python 3.11+
* [Ollama](https://ollama.com/) installed on your host machine.
* ~300 MB disk space for project files (plus ~3GB for local Ollama models).

### 1. Install & Pull Local Models

Ensure Ollama is running in your background tray, then open your terminal and download the required lightweight models:

```bash
# Pull the embedding model (for semantic scoring)
ollama pull nomic-embed-text

# Pull the chat model (for reasoning and explanations)
ollama pull llama3.2:1b

```

### 2. Clone the repository

```bash
git clone https://github.com/shalombebx/smart-resume-screener.git
cd smart-resume-screener

```

### 3. Create a virtual environment

```bash
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate

```

### 4. Install dependencies

```bash
pip install -r requirements.txt

```

### 5. Configure environment variables

```bash
cp .env.example .env

```

Edit `.env` to ensure it points to the local models:

```env
OLLAMA_CHAT_MODEL="llama3.2:1b"

```

### 6. Create required directories

```bash
mkdir -p data/uploads data/cache exports

```

## ▶️ How to Run Locally

### Option A: Docker (Recommended)

The Docker container is pre-configured with `host.docker.internal` networking to seamlessly communicate with Ollama running on your host machine.

```bash
# Build and launch the container
docker compose up --build

```

Open **http://localhost:8000/api/docs** to access the Swagger UI, which includes a patched OpenAPI 3.0.2 schema for proper multipart file uploads.

### Option B: Backend API only

```bash
python main.py

```

Open: **http://localhost:8000/api/docs** (Swagger UI)

### Option C: Run the demo script

```bash
python demo.py

```

This runs the full pipeline on the 5 sample résumés and prints a rich terminal ranking table.

### Option D: Use the web frontend

1. Start the backend: `python main.py` or via Docker.
2. Open **http://localhost:8000/** — the backend serves `frontend/index.html` itself.
3. Upload résumés, paste the JD, click **Run AI Screening**.

> ⏱️ **Performance Note:** Because this runs entirely locally on your CPU/integrated graphics, processing time depends on your hardware. For example, processing 3 résumés through the full extraction, embedding, and 1B reasoning pipeline typically takes around 10–12 minutes on a standard ultra-mobile CPU (e.g., Intel UHD Graphics / i5).

## 🔑 API Reference

All endpoints are prefixed with `/api`. Full interactive docs at `/api/docs`.

### Upload Résumés

```http
POST /api/resumes/upload
Content-Type: multipart/form-data

files: [file1.pdf, file2.docx, ...]

```

### Run Analysis

```http
POST /api/analysis/run
Content-Type: application/json

{
  "job_description": "Senior ML Engineer with 5+ years...",
  "candidate_ids": null
}

```

### Get & Export Results

```http
GET /api/results/{session_id}
GET /api/results/{session_id}/export?format=csv
GET /api/results/{session_id}/export?format=json

```

## Bias and Responsible Use

Automated hiring tools require strict scrutiny regarding fairness and algorithmic bias. Machine learning models can inadvertently learn and amplify biases present in historical training data, potentially disadvantaging candidates based on demographic, geographic, or socioeconomic factors.

**Guidelines for Responsible AI Use:**

* **Human in the Loop:** This system is designed as an assistive tool to help surface qualified candidates efficiently. It is not intended to replace human judgment.
* **Active Bias Detection:** We are planning a dedicated bias detection module to actively monitor and mitigate unfair filtering patterns.
* **Continuous Auditing:** Users implementing this tool are highly encouraged to conduct regular audits of their screening outcomes.
